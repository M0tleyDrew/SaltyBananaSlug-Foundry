# Automation coverage · 0.1.3

All twelve transformations have complete staged selection catalogs. The tables below describe configured assistance, not complete automation of all rule text. Read the summary and manual steps on the generated sheet feature.

**Manual**: reference card and/or contextual trackers. **Assisted**: configured native activities or passive effects; follow-up conditions and contextual restrictions can still require manual resolution.

Specialized runtime hooks (Bloodied, rests, forms, damage, d20 flaws) are additional to the descriptor counts; see README for their scope.
