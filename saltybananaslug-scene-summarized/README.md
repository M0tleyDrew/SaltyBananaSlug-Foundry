# SaltyBananaSlug's Scene Summarized

A Foundry VTT v13 module that creates a detailed, linked Journal dossier from any Scene.

## Installation

1. Extract the `saltybananaslug-scene-summarized` folder into Foundry's `Data/modules` directory.
2. Enable **SaltyBananaSlug's Scene Summarized** in your world.
3. Reload the world.
4. Drag the automatically created launcher macro from the Macro Directory to your hotbar.

A standalone copy of the macro command is also included as `launcher-macro.js`.

## Generated Journal pages

- Scene Overview
- Cast & Creatures
- Items, Loot & Equipment
- Actor features, actions, and spells are kept with each creature on Cast & Creatures
- Map, Images & Tiles
- Audio & Atmosphere
- Lighting, Vision & Environment
- Notes, Drawings, Templates & Regions
- Walls, Doors & Technical Layout
- Media Index, when selected
- Raw Scene Data, when selected or when using Exhaustive detail

## Player access

- **GM only:** no default player permission.
- **Players can view — protect GM details:** gives players Observer permission while putting hidden tokens, statistics, traps, coordinates, and technical data in Foundry Secret blocks.
- **Players can view everything:** gives players Observer permission without automatic redaction.

The separate **Show players immediately** option pops the Journal open for currently connected players. Permission and immediate display are intentionally separate controls.

## Other behavior

- Can update an earlier summary for the same Scene.
- Only pages generated by the module are replaced; manually added pages are preserved.
- Can set the Journal as the Scene's linked Journal.
- Can pin a clickable map Note using the SaltyBananaSlug logo.
- Lists module flag scopes and can include complete raw Scene JSON, which helps capture module-driven tile actions and other custom data.
- Supports any game system, with additional human-readable detail for D&D 5e Actor and Item data.

## v1.0.4 — SBS Containers & Merchants integration
- Recognizes tokens managed by **SaltyBananaSlug's Containers** and **SaltyBananaSlug's Merchants**.
- Follows those tokens to their separate hidden inventory Actors and companion Journals.
- Adds Containers and Merchants to scene counts and creates a dedicated **Containers & Merchants** summary page.
- Includes container contents and merchant stock/treasury data on the Items page.
- Avoids presenting generated shell Actors as ordinary NPC/monster statblocks.
- Includes container/merchant item art and merchant greeting audio in the optional Media Index.
- Exhaustive Raw Data now includes the external inventory Actors used by those modules.
- Remains compatible with scenes that do not use either module.
