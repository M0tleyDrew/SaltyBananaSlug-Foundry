# SaltyBananaSlug's Web Viewer v1.2.0

## Changes in 1.2.0

- Website shares now appear as a link card with Open in New Tab and Copy Link instead of a blocked iframe.
- YouTube uses the official embed format, explicit origin/referrer settings, privacy-enhanced hosting by default, and the YouTube IFrame Player API for error reporting.
- YouTube includes retry buttons for both privacy-enhanced and standard hosts.
- YouTube error 153 and autoplay blocking now produce readable messages.
- Temporary image and audio sharing remain unchanged and do not save files into the world data folder.

## Install

Extract this folder into `Data/modules/` so the final path is:

`Data/modules/saltybananaslug-web-viewer/module.json`

Restart Foundry and enable the module.
