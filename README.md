# SaltyBananaSlug Foundry Modules

A collection of SaltyBananaSlug modules for Foundry VTT.

## Included modules

- Party Viewer
- Actor Journal
- Card Games
- Character Sheets
- Containers
- Item Uploader
- Merchants
- Quests & Objectives
- Scene Piles
- Scene Summarized
- Web Viewer
- Danger Zones
- Factions
- Lore Module
- Message Cantrip
- NPC Memories

The SBS Environment module/release folder is intentionally not included in this repository.
