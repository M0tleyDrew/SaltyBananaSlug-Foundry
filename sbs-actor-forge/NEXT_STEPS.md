# Actor Forge release status

## 1.0.0

The tested 0.5.0 build is promoted to 1.0.0. Runtime mechanics, artwork and import behavior are preserved; build labels, workbooks, release documentation and GitHub installation metadata are updated.

Imports, update/Undo, saved presets after reload, saved source libraries and compendium workflows have been confirmed in-game. The separate player-account GM-note permission check remains untested in-game and is documented in TEST_REPORT.md. Automated coverage for that behavior passes.

No additional test release is required for this promotion. Future changes should address a reported issue or a requested feature.
