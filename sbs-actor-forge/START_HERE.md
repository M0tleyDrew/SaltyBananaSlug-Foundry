# SaltyBananaSlug’s Actor Forge — v1.0.0

1. Install through SBS Environment or the direct manifest in README. For a manual install, replace the complete Data/modules/sbs-actor-forge folder with the folder from the 1.0.0 ZIP.
2. Restart/reload Foundry. Open the existing SBS icon macro or Settings launcher; it should show **1.0.0**.
3. Run **Compatibility Check** with your normal modules enabled.
4. Import **SaltyBananaSlug_Actor_Forge_Main_Test_v1.0.0.xlsx** using World destinations. **No JSON attachment is needed.**
5. Pip: class skills Arcana + Investigation; any background gaming set; either background spell; Charisma for each Signal Slug spell-ability prompt. The tier actors need no choices.
6. Follow Main’s Read Me/Test Plan: 22 cases for presets, saved libraries, compendium import/update/Undo, inline notes and retained mechanics.
7. For pack tests, create/unlock empty native World compendiums of Actor and Item types. Select them in Import. Advancements are deferred until World import; parties/crews require World actors.
8. Update Test must use Main’s destination collections. Undo immediately afterward. Only the latest import is undoable; the original Main actors remain after Undo of Update.

Downloads are a module ZIP plus separate workbooks. Optional Source, matching source JSON, Blank and older regression fixtures are in the ZIP’s workbooks folder.

For saved-library checks, upload matching source JSON once in Sources & Libraries and save a name. Reload, then select that saved library while importing Source Test; no re-upload is needed.
